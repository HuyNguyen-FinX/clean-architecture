# Case Study 05: Loan Service

Loan Service có nhiều rule nghiệp vụ nên phù hợp để học DDD kết hợp Clean Architecture.

Trọng tâm:

- Loan application lifecycle.
- Risk score.
- Approval policy.
- Gateway sang credit scoring hoặc core banking.
- Audit trail.
- Disbursement workflow.

Kết luận chính: Bounded Context và ubiquitous language quan trọng hơn việc chia folder thật sâu.

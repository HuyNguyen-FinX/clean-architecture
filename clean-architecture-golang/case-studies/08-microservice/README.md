# Case Study 08: Microservice

Microservice case study dùng để phân biệt Clean Architecture với distributed system design.

Trọng tâm:

- Service boundary.
- Data ownership.
- API contract.
- Eventual consistency.
- Observability xuyên service.
- Deployment và operational complexity.

Kết luận chính: Clean Architecture có thể giúp bên trong mỗi service sạch hơn, nhưng không tự giải quyết network failure hoặc distributed transaction.

# Case Studies

Case study là nơi áp dụng nguyên tắc vào hệ thống có context cụ thể. Mỗi case phân tích:

- Requirements.
- Domain.
- Use Cases.
- Boundaries.
- Interfaces.
- Infrastructure.
- Database.
- Transactions.
- Concurrency.
- Error Handling.
- Testing.
- Observability.
- Trade-offs.

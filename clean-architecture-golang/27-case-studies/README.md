# 27 Case Studies

## Tại sao cần học?

Case study giúp nối nguyên tắc architecture với hệ thống thật. Mỗi case sẽ phân tích requirements, domain, use cases, boundaries, interfaces, infrastructure, transactions, concurrency, error handling, testing, observability và trade-off.

## Danh sách Case Study

- Todo API.
- E-commerce Order.
- Payment Service.
- Banking Account.
- Loan Service.
- Kafka Worker.
- Batch Processing.
- Microservice.

## Cách đọc

Không bắt đầu bằng folder. Bắt đầu bằng câu hỏi:

- Actor cần đạt điều gì?
- Business rule nào sống lâu?
- Detail nào có thể thay đổi?
- Boundary nào đáng trả chi phí?

## Mastery Check

- [ ] Tôi biết so sánh nhiều thiết kế hợp lệ.
- [ ] Tôi biết nói rõ trade-off thay vì đưa một đáp án duy nhất.

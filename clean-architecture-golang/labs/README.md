# Labs

Labs được thiết kế theo hướng làm từng lớp nhỏ, không nhảy ngay vào full project. Mỗi lab có `starter/` và `solution/` để bạn tự làm trước khi xem hướng giải.

## Danh sách

```text
lab-01-simple-domain
lab-02-usecase
lab-03-repository
lab-04-postgresql
lab-05-http
lab-06-dependency-injection
lab-07-testing
lab-08-transaction
lab-09-kafka
lab-10-redis
lab-11-refactoring
lab-12-full-application
```

## Cách làm lab

1. Đọc README của lab.
2. Chạy test trong `starter/` nếu có.
3. Sửa code ở `starter/` cho đến khi đạt yêu cầu.
4. So sánh với `solution/`.
5. Trả lời câu hỏi mastery trước khi chuyển lab tiếp theo.

Không nên đọc solution trước. Mục tiêu của lab là tập ra quyết định boundary, không chỉ copy code.
